title: 兼容性与系统要求
---

## PC浏览器

- **✔ 技术框架：** Vue.js, React, BootStrap, Vallian JS/HTML, etc.

- **✔ 浏览器：** Chrome, Edge, Safari, FireFox, etc.

## 移动浏览器

- **✔ 技术框架：** Vue.js, React, BootStrap, Vallian JS/HTML, etc.

- **✔ 浏览器：** WeChat/Alipay built-in browsers, Chrome Mobile, Safari Mobile, etc.

## 移动端APP

- **✔ 技术框架：**  React Native/Flutter（需定制化开发）

## 性能影响

- **资源占用：**
  - SDK加载时间: 小于50ms  
  - 内存占用: 小于5MB  
  - 峰值CPU占用: 小于3%
