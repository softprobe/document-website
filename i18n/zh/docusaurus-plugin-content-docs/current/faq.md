# 常见问题

找到关于我们平台的常见问题的答案。

## 一般问题

### 这个平台是什么？

我们的平台是一个综合的SaaS解决方案，帮助企业管理他们的数据、与第三方服务集成并构建强大的应用程序。

### 如何开始？

查看我们的[快速开始指南](/docs/getting-started/installation)获取分步指导。

### 有免费层吗？

是的！我们提供免费层，包括：
- 每月1,000个API请求
- 1个项目
- 基本支持

### 定价计划是什么？

我们提供三个计划：

- **免费**：$0/月 - 适合测试
- **专业版**：$29/月 - 适合成长中的企业
- **企业版**：自定义定价 - 适合大型组织

## 技术问题

### 如何与API进行身份验证？

在Authorization头中使用API密钥。有关详细信息，请参阅我们的[身份验证指南](/docs/api/authentication)。

### 速率限制是什么？

速率限制因计划而异：
- 免费：每小时1,000个请求
- 专业版：每小时10,000个请求
- 企业版：自定义限制

### 支持哪些编程语言？

我们提供以下SDK：
- JavaScript/Node.js
- Python
- PHP
- Ruby

### 如何处理错误？

所有错误都遵循一致的格式。有关错误代码和处理，请查看我们的[API参考](/docs/api/endpoints)。

## 计费

### 计费如何工作？

计费是月度的，基于您的使用情况。您在每个月初被收费。

### 我可以更改我的计划吗？

是的！您可以随时从仪表板升级或降级您的计划。

### 你们提供退款吗？

我们为所有付费计划提供30天退款保证。

### 你们接受哪些付款方式？

我们接受所有主要信用卡和PayPal。

## 安全

### 你们如何保护我的数据？

我们使用行业标准的安全措施：
- 端到端加密
- 定期安全审计
- SOC 2合规
- GDPR合规

### 我的数据存储在哪里？

数据存储在多个地理区域的加密安全数据库中。

### 我可以导出我的数据吗？

是的！您可以随时从仪表板导出所有数据。
