# 套餐与价格

Softprobe 提供三种套餐以满足不同阶段与规模：

- 免费版（Free）— 固定配额，适合评估体验
- 商业版（Business/Pro）— 固定配额，适合成长型团队
- 企业版（Enterprise）— 按用量计费，随业务弹性扩展

## 配额与限制（示例）
- 免费版：基础存储、席位与 API 速率限制；超额后受限
- 商业版：更大的存储与更高配额；可在超额时引导升级或计费
- 企业版：无固定配额，按实际用量计费

## 计费模型
- 免费版：￥0/月
- 商业版（固定配额）：固定月费
- 企业版（按用量）：按存储、API 调用、月活等维度计费

如需企业定制或更高配额，请联系 support@softprobe.ai。
