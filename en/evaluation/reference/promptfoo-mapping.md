# Promptfoo field mapping

This page is legacy context only.

Softprobe does **not** maintain a complete Promptfoo-to-JSON field map.
Instead, Promptfoo runs through a pinned framework runner and preserves native result bundles.

Use these pages:

- [Framework adapters](/en/evaluation/reference/framework-adapters)
- [Promptfoo integration](/en/evaluation/guides/promptfoo-integration)
- [Quick start](/en/evaluation/getting-started)

Key rule: unsupported or lossy fields remain in native artifacts and are surfaced via diagnostics, not silently dropped.
