## 敏感信息处理

### 1. 数据收集阶段
- **自动数据脱敏**  
  预置对密码、手机号等常见敏感字段的保护机制，支持通过CSS选择器自定义脱敏规则，确保隐私数据不被存储或回放。  
- **动态内容排除**  
  使用HTML属性标记敏感元素（如`data-sp-ignore`），可从记录过程中主动排除指定内容。具体实现详见接入文档。

### 2. 数据传输与存储
- **端到端加密**  
  - 传输层：采用AES-256加密技术保护日志传输  
  - 存储层：叠加TLS 1.3协议实现双重加密  
- **法规合规性**  
  全面遵守GDPR（欧盟通用数据保护条例）、CCPA（加州消费者隐私法案）、PIPL（中国个人信息保护法）等全球隐私法规。

### 3. 精细化权限控制
  基于角色的会话回放访问权限管理，所有数据检索操作均生成审计日志。
