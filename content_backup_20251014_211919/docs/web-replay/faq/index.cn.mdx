## 关于项目管理

**什么是tenantId和appId**

- tenantId是客户的唯一标致，一般一个组织有且只有一个tenantId；appId是应用的唯一标识，用于区分组织下的每一个独立的应用（如每一个网页/客户端等）

**怎么获取tenantId和appId**

- 请与Softprobe团队沟通，分配唯一标致的tenantId与appId

## 关于技术方案

**是否支持移动端H5页面**

- 完全兼容移动端浏览器，提供手势操作（双指缩放、长按）的完整采集与回放支持

**数据存储周期是多久**

- 默认保留365天，如需要自定义存储时间和自定义数据库规范请与Softprobe技术团队联系
