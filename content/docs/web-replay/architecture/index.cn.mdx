## 分层架构设计  

**Softprobe** 采用三层模块化架构，实现用户行为全生命周期管理：  

### 1. 数据采集层  
- **多维度捕获**：通过轻量级 SDK 实时采集：  
  - **DOM 结构变更**：包括元素增删、样式更新  
  - **用户交互事件**：点击、滚动、输入、路由跳转  
  - **性能指标**：首屏时间、FCP（首次内容绘制）、卡顿帧率  
- **智能节流**：自适应采样算法减少低价值事件捕获  

### 2. 数据处理层  
- **数据优化**：  
  - 日志压缩（GZIP + Protocol Buffers）  
  - AES-256 + TLS 1.3 双重加密传输  
- **状态重建引擎**：  
  - 基于初始快照与增量 DOM 变更记录  
  - 行为序列重组算法还原操作时序  
  - 生成时间轴对齐的类视频流数据  

### 3. 分析展示层  
- **可视化能力**：  
  - 热力图（点击密度/滚动深度）  
  - 用户会话路径图谱  
  - 自定义漏斗/留存率报表  

## 非录屏技术核心优势  

### 1. 动态渲染优化  
- **带宽节省 80%**：相比传统视频流，仅传输结构化日志  
- **跨版本兼容**：基于实时 DOM 快照记录，规避前端迭代导致的回放失真  

### 2. 毫秒级操作还原  
- **时空精准映射**：  
  - 操作坐标误差 < 1px  
  - 事件时间戳精度 ±10ms  
- **交互模拟能力**：  
  - 支持 0.5x-4x 倍速播放  
  - 关键节点（如支付按钮点击）快速跳转
