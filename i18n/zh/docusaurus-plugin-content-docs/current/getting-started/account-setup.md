## 步骤 1：注册 Softprobe 账户

### 1.1 访问注册页面

1. 打开浏览器，访问 [https://dashboard.softprobe.ai](https://dashboard.softprobe.ai)
2. 点击页面右上角的 **"注册"** 按钮

### 1.2 填写注册信息

在注册页面填写以下信息：

- **邮箱地址**：用于登录和接收通知
- **密码**：建议使用强密码（至少8个字符，包含字母、数字和特殊字符）
- **确认密码**：重新输入密码进行确认

### 1.3 验证邮箱

1. 点击 **"创建账户"** 按钮
2. 检查您的邮箱，查看验证邮件
3. 点击邮件中的验证链接完成邮箱验证

### 1.4 登录账户

1. 返回 [https://softprobe.ai](https://softprobe.ai)
2. 点击 **"登录"** 按钮
3. 输入您的邮箱和密码
4. 点击 **"登录"** 完成登录

## 步骤 2：创建租户组

### 2.1 访问租户管理页面

登录后，在左侧导航菜单中找到并点击 **"租户管理"** 或 **"Tenant Management"**。

### 2.2 创建新租户组

1. 点击 **"创建租户组"** 按钮
2. 填写租户组信息：
   - **租户组名称**：为您的组织选择一个描述性名称
   - **描述**：（可选）添加关于此租户组的简短描述

### 2.3 配置租户组设置

1. 选择适合您需求的订阅计划
2. 配置任何必要的权限设置
3. 点击 **"创建"** 完成租户组创建

## 步骤 3：生成 API 密钥

### 3.1 访问 API 密钥管理页面

在租户组仪表板中，找到并点击 **"API 密钥"** 或 **"API Keys"** 部分。

### 3.2 创建新的 API 密钥

1. 点击 **"创建 API 密钥"** 按钮
2. 为您的 API 密钥输入一个描述性名称
3. 选择适当的权限级别（通常选择 "读写" 权限）

### 3.3 重要：保存配置文件

当您点击 **"创建 API 密钥"** 后：

1. **自动下载**：系统会自动下载一个名为 `minimal.yaml` 的配置文件
2. **文件内容**：此文件包含：
   - 您的 API 密钥
   - SP-Istio WASM 插件配置
   - 连接到 Softprobe 服务所需的设置

3. **重要提醒**：
   - ⚠️ **这是一次性下载** - 配置文件只会在创建 API 密钥时下载一次
   - 💾 **立即保存** - 请将此文件保存到安全位置
   - 🔄 **如果丢失** - 您需要删除当前 API 密钥并创建新的密钥

### 3.4 API 密钥格式

Softprobe API 密钥的格式为：
```
sk_live_[随机字符串]  # 生产环境
sk_test_[随机字符串]  # 测试环境
```

## 常见问题

### Q1：如果我丢失了 minimal.yaml 配置文件怎么办？

**答：** `minimal.yaml` 文件只在创建 API 密钥时下载一次。如果您丢失了它：
1. 从仪表板中删除当前的 API 密钥
2. 创建新的 API 密钥（这将生成新的 `minimal.yaml` 文件）
3. 立即保存新的配置文件

### Q2：如果我忘记保存 API 密钥怎么办？

**答：** 使用新系统，您不需要手动复制 API 密钥。它会自动嵌入到创建密钥时下载的 `minimal.yaml` 文件中。只需确保安全保存该文件即可。

### Q3：API 密钥可以重复使用吗？

**答：** 是的，API 密钥可以在多个环境中使用，但建议：
- 为生产环境使用单独的 API 密钥
- 为开发/测试环境使用单独的 API 密钥

### Q4：如何验证我的配置是否正确？

**答：** 部署配置后，您可以：
1. 检查 `minimal.yaml` 是否正确应用
2. 验证 Istio 服务网格是否已安装
3. 在 Softprobe 仪表板中查看是否有数据流入

### Q5：支持哪些环境？

**答：** SP-Istio Agent 支持：
- **Kubernetes 集群**：1.19+ 版本
- **Istio 服务网格**：1.10+ 版本
- **操作系统**：Linux（推荐 Ubuntu 18.04+）

### Q6：如何检查配置是否生效？

**答：** 部署 `minimal.yaml` 后，您可以：
1. 检查 `minimal.yaml` 是否正确应用
2. 验证 Istio 服务网格是否已安装
3. 在 Softprobe 仪表板中查看是否有数据流入
