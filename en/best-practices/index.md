# Best practices

Ways to combine several features to get one complete job done. Each one comes with the record of a real run.

| Practice | What it solves |
|---|---|
| [Regression testing on every release](/en/best-practices/release-regression) | On every release, the pipeline tests the new version with real requests recorded in production; if results change, it stops and says which commit changed them |
