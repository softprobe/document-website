---
title: 快速开始
---

让我们在5分钟内快速开始安装我们的SDK。

## 步骤1：安装SDK

通过npm安装依赖包（或直接引入CDN脚本）：

```bash
npm install @softprobe/softprobe-web-record-sdk --save
```

## 步骤2：初始化配置
在项目入口文件（如main.js/app.js）中初始化Softprobe：

```javascript
// 异步加载SDK以优化首屏性能
const initializeAnalytics = async () => {
  try {
    const { default: initSoftprobe } = await import('@softprobe/softprobe-web-record-sdk');
    initSoftprobe({
      appId: 'appId-softprobe-test-page', // 替换为你的应用ID
      tenantId: 'tenant-softprobe-test-user',          // 替换为租户ID
      tags: { 
        userRole: 'guest',                  // 自定义标签（可选，用于分类检索）
      },
      privacy: {
        maskSelectors: ['.credit-card', '#password'] // 定义需掩码的DOM元素
      }
    });
  } catch (error) {
    console.error('Softprobe初始化失败:', error);
  }
};

initializeAnalytics();
```

## 步骤3：查看回放与分析数据

**登录管理后台**

- 访问 [Softprobe仪表盘](https://dashboard.softprobe.ai/)，使用账户密码或SSO登录。

**选择目标页面** 

- 在左侧导航栏选择对应的组织与应用，进入“页面列表”。

![Session List](./resource/dashboard-session-list.png)

**查看用户会话**

- 进入 Session回放面板，按时间、设备类型、标签等筛选会话。
- 点击单条会话，可实时回放操作流程，查看事件时间线及关联数据（如点击坐标、滚动深度）。

![Session List](./resource/dashboard-session-replay.png)

**生成分析报告**

- 进入 [分析中心](https://dashboard.softprobe.ai/heatmap)，导出热力图、转化漏斗报表或设置自动化告警规则（如“当页面退出率>60%时触发通知”）。

![Heatmap](./resource/dashboard-heatmap.png)
