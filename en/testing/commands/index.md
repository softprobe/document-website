# Commands

Softprobe user workflows use the `sp` command.

Primary lifecycle:

```bash
sp setup
sp code
sp doctor
sp upgrade
```

Record/replay automation remains available through `sp app`, `sp agent`, `sp policy`, `sp record`, `sp replay`, `sp diagnose`, `sp trace`, and `sp logs`.

Detailed command pages are being consolidated from the previous CLI section into Testing.
