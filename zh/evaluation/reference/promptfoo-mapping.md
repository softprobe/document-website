# Promptfoo 字段映射

本页仅为遗留上下文。

Softprobe **不**维护完整的 Promptfoo-to-JSON 字段映射表。
相反，Promptfoo 通过已 pin 的 framework runner 运行，并保留原生 result bundle。

请使用这些页面：

- [Framework runners](/zh/evaluation/reference/framework-adapters)
- [Promptfoo 集成](/zh/evaluation/guides/promptfoo-integration)
- [快速开始](/zh/evaluation/getting-started)

关键规则：不支持或有损的字段留在原生制品中，并通过诊断暴露，而不是静默丢弃。
